# Experience in installing a Kali Linux vbox
#  Cybersecurity Home Lab Setup & Environment Documentation

Проект по развертыванию, тонкой настройке и документированию изолированной виртуальной лаборатории для практического изучения информационной безопасности, системного администрирования и анализа защищенности.

---

## Спецификация оборудования и ресурсов

Лаборатория развернута на базе **VirtualBox** с учетом жестких лимитов оперативной памяти хост-системы (8 GB RAM) для сохранения стабильности и высокого отклика основной ОС.

* **Хостовая ОС:** Windows 11 Home / Pro
* **Гостевая ОС:** Kali Linux (Rolling Release)
* **Гипервизор:** Oracle VM VirtualBox
* **Выделенная ОЗУ:** 3008 MB (3 GB) — оптимальный баланс для работы графического окружения без переполнения Swap-файла хоста
* **Выделенный ЦП:** 2 виртуальных ядра (vCPU) — обеспечение многопоточности при сканировании и компиляции
* **Тип накопителя:** Динамический виртуальный диск (VDI)
* **Размер накопителя:** 20 GB — выделение памяти по требованию без предварительной забивки реального SSD
* **Сетевой режим:** NAT (с перспективой настройки Host-Only / Bridged для изоляции сетевых атак)

## Пошаговый процесс развертывания и первоначальной настройки

### 1. Конфигурация гипервизора
* Создана новая виртуальная машина с типом `Linux` и версией `Debian (64-bit)`.
* Выставлены оптимальные лимиты процессора и оперативной памяти в зеленой зоне нагрузок.
* Отключена опция EFI для снижения накладных расходов при загрузке и предотвращения конфликтов с загрузчиком GRUB.
